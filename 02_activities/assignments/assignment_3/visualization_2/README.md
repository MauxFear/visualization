# Toronto Crime Map Visualization

A simple interactive web visualization that displays crime rates across Toronto neighborhoods. Users can explore crime data by year and crime type through an interactive, color-coded map.

## Data Source

This visualization uses data from the City of Toronto Open Data Portal:
- [Neighborhood Crime Rates](https://open.toronto.ca/dataset/neighbourhood-crime-rates/)
- [Toronto Neighborhoods Boundaries](https://open.toronto.ca/dataset/neighbourhoods/)

## Requirements

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Node.js (for running the local server)

## Running the Visualization

1. Make sure you have Node.js installed
2. Open a terminal in the project directory
3. Run the server with: `node server.js`
4. The visualization will open in your default browser

Alternatively, you can use:
- Python: `python -m http.server`
- Node.js: `npx http-server`

Then open `index_main.html` through your local server.

Note: You must use a local web server to view the visualization properly.
